# LookDog

Tooling and import records for [lookdog.club](https://lookdog.club) — a WooCommerce
affiliate site listing dog products sourced from AliExpress.

## How the catalogue works

Products are WooCommerce **external/affiliate** products. Each one:

- links out to AliExpress via an affiliate link generated by the AliExpress
  Portals API (so clicks are attributed to the site's tracking ID),
- carries a "Check Price on AliExpress" button instead of a stored price, so the
  catalogue never shows a stale figure,
- stores its source AliExpress item ID in the `_lookdog_ae_id` post meta key,
  which is what makes imports idempotent,
- has a main image plus a five-image gallery sideloaded into the media library,
- includes an affiliate disclosure in both the short and long description.

## Credentials

The API credentials live in `wp-config.php` on the server as PHP constants and are
deliberately **not** stored in this repository:

```php
define( 'ALIEXPRESS_APP_KEY', '…' );
define( 'ALIEXPRESS_APP_SECRET', '…' );
define( 'ALIEXPRESS_TRACKING_ID', '…' );
```

Everything in `scripts/` reads those constants. Never hard-code the secret.

## Server-side helpers

Two files do the work, both on the WordPress host:

| File | Purpose |
| --- | --- |
| `wp-content/mu-plugins/lookdog-aliexpress.php` | API client: request signing, product lookup, image sideloading |
| `wp-content/novamira-sandbox/lookdog-toy-importer.php` | Turns cached product data into WooCommerce external products |

A copy of the importer is kept in `scripts/` in this repo.

### API signing

The AliExpress Portals gateway (`https://api-sg.aliexpress.com/sync`) expects
parameters sorted by key, concatenated as `key1value1key2value2…`, then signed with
HMAC-SHA256 using the app secret and uppercased. `lookdog_ae_call()` handles this.

### Useful API methods

- `aliexpress.affiliate.category.get` — first and second level categories
- `aliexpress.affiliate.product.query` — keyword search (Pet Products is `100006664`)
- `aliexpress.affiliate.productdetail.get` — full detail plus `promotion_link`,
  accepts up to ~20 comma-separated IDs per call

## Import workflow

1. Run several targeted keyword searches constrained to the Pet Products category
   and collect the union of results.
2. Filter out listings that are not dog toys — cat-only items, accessories,
   grooming tools — and drop anything below roughly 90% positive feedback.
3. Curate by hand for distinct product *types*. Keyword search returns many
   near-duplicate listings of the same item, so this step matters.
4. Fetch full details for the shortlist to get `promotion_link` and images.
5. Call `lookdog_toy_create()` per product in batches of three or four; larger
   batches risk hitting PHP's max execution time during image sideloading.
6. Verify: confirm every affiliate link 302-redirects to the expected item ID and
   still carries `aff_trace_key` / `aff_fcid`.
